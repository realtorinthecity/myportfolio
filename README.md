# Charandeep Singh marketing portfolio

A responsive, static marketing portfolio prepared for GitHub Pages. It is based on the supplied portfolio and uses the approved imagery extracted from it.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload the complete contents of this folder, keeping `assets/` beside `index.html`.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch** and select the `main` branch with the `/ (root)` folder.
5. Save. GitHub will provide the public site address within a few minutes.

## Files

- `index.html` — the page content
- `styles.css` — responsive visual design
- `script.js` — mobile menu and active navigation states
- `assets/` — source portfolio imagery used by the page

No build step, package installation, or server is required.
